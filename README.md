# Показ

Особистий кабінет побутового споживача електроенергії. Користувач вносить
показ лічильника, бачить суму і сплачує, розуміє своє споживання й дізнається
про відключення.

**Мета:** щомісячна рутина зі світлом займає хвилину і не лишає питань
«чи прийняли показ», «скільки платити» і «чому стільки».

- **Для кого:** власники й орендарі квартир і будинків, 25–65 років, часто з кількома об'єктами (батьки, дача).
- **Ключова задача:** внести показ (вручну або за фото) і знати суму.
- **Модель:** кабінет одного постачальника; багато об'єктів і багато людей з ролями (власник, учасник, спостерігач).
- **Платформа:** десктопний веб, далі адаптив до телефона.
- **Стек прототипу:** React + Vite + TypeScript, дані на моках.
